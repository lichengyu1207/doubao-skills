# yihaiyoudao — 内容审核与原创改造

## 核心定位

本 Skill 把一套经过大量实战检验的内容方法论固化为可复用流程，覆盖四个能力：

1. **原创性审核**：判断内容是否为拼凑/洗稿/AI套话，还是真正有个人辨识度的原创。
2. **限流风险识别**：预判公域平台的审核红线，识别敏感词与风险表述。
3. **观点性改造**：把资讯、感悟、故事改造成有立场、有判断、有认知框架的观点内容。
4. **风格统一**：保持作者一贯的冷峻、锋利、有格局感的表达风格。

执行标准（交付前必须满足）：

| 维度 | 标准 |
|---|---|
| 原创性 | ≥ 高（有个人框架和辨识度） |
| 限流风险 | ≤ 低（无高危词，无敏感话题） |
| 观点性 | ≥ 强（有立场、有判断、有反转） |
| 风格 | 统一（冷峻、锋利、有格局） |

## 分支判定（收到任务先判定类型）

1. **审核已有内容**（判断原创性/有无风险）→ 走「审核工作流」
2. **修改已有内容**（降险改写/观点化改造）→ 走「修改工作流」
3. **创作新内容**（给选题或素材，要观点文）→ 走「创作工作流」
4. **多平台适配**（同一内容改到其他平台）→ 按 `references/style-guide.md` 的平台适配规则执行

## 自动化脚本（一键审核，推荐优先使用）

同目录 `scripts/audit.py` 可对一篇内容自动输出：原创性等级 + 风险词扫描（自动读取 `references/risk-lexicon.md` 词库）+ 修改建议表：

- `python scripts/audit.py 文章.txt` → 审核报告（原创性 + 限流风险 + 替换建议）
- `python scripts/audit.py 文章.txt --json` → 结构化 JSON 结果

有 Python 环境时先跑脚本得到扫描结果，再人工复核精修；无 Python 环境时按下方工作流手动执行。

1. **每次使用结束**：把新学到的风险词 / 替换经验记入 `memory/learning-log.md`（脚本：`python scripts/audit.py --note "..."`）。
2. **扩充个人词库**：发现新风险词，用 `python scripts/audit.py --remember "词|类别|替换建议"` 加入 `memory/risk-additions.md`，下次扫描自动生效。
3. **每周复盘**：把出现 2 次以上的经验固化进 `references/risk-lexicon.md` 词库或正文模板。
4. **学习只在本机**：所有学习记录只存在本技能 `memory/` 目录，不上传、不外发。
5. **新任务入口**：拿不准用哪个技能时，先跑决策层自动选技能：`python pi-jev/scripts/pi_jev.py "任务"`（同包 pi-jev 技能，Jev 式路由，无需 API）。

## 审核工作流（收到一篇待审核内容）

按顺序执行：

1. **通读判定原创性**：对照 `references/originality.md` 的标准，给出原创性等级（极高/高/中/低）与理由。
2. **三级风险扫描**：逐段标记风险词，按红（极高危）/橙（高危）/黄（中危）分类，对照 `references/risk-lexicon.md` 的词库逐条核对。
3. **逐段精修**：保留骨架、替换皮肉，按「修改工作流」的六条替换法执行。
4. **检查收束**：确保结尾有力且为正向收束；批判性内容必须有建设性结尾。
5. **输出完整版 + 审核报告**：报告按下方「审核报告模板」输出，附修改逻辑表（原文→改后→风险类型→处理方式）。

## 修改工作流

**核心原则：保留骨架，替换皮肉。** 作者的核心观点、逻辑链条、原创框架全部保留，只替换敏感词和风险表述。

六条替换法（详细词库见 `references/risk-lexicon.md`）：

1. **去宗教化**：将"修行/道心/业力/灵魂等级"框架替换为"自我成长/内在成熟/惯性模式"框架。
2. **去医学化**：将"PTSD/抑郁/精神病/人格障碍"替换为"创伤感/心理困境/内在冲突状态"。
3. **去政治化**：将"阶级/资本家/底层人群/剥削"替换为"阶层/有产者/普通劳动者/消耗"。
4. **去攻击性**：将"傻逼/垃圾/滚/巨婴/捞女"替换为中性表述，不用侮辱性词汇。
5. **去绝对化**：将"没有人/唯一/所有/永远"替换为"不要指望/你可以/大多数人"。
6. **去引流**：删除所有"进群/课程/私信/粉丝群"等引流内容。

外加一条：**增加正向收束**——批判性内容后补一句建设性结尾，收束句式库见 `references/risk-lexicon.md`。

## 创作工作流（写观点性内容）

**选题原则**（详见 `references/style-guide.md`）：

- 从近期发生的事切入（新闻、个人经历、观察），不写泛泛的"人生感悟"。
- 必须有具体观点，观点要有反转感：不是"努力很重要"，而是"你以为的努力其实是逃避"。

**结构模板**（场景→问题→拆解→反转→收束）：

| 部分 | 篇幅 | 要求 |
|---|---|---|
| 1. 场景切入 | ≤300字 | 一个具体的人、事、场景，带出核心矛盾 |
| 2. 提出问题 | ~100字 | 把场景提炼成一个有张力的问题 |
| 3. 拆解分析 | 800-1200字 | 2-3个层次递进；每层用一个概念或比喻支撑；结合个人经历或观察 |
| 4. 反转/深化 | ~300字 | 给出一个反直觉的判断 |
| 5. 收束 | ~100字 | 一句有力的话收尾，不拖泥带水 |

**写作时注意**：标题有格局感，开头有冲突，中间有框架，结尾有金句。

**发布前自检**（逐条过）：

- [ ] 是否有限流风险词（对照 `references/risk-lexicon.md` 词库）
- [ ] 是否有鲜明观点（不是资讯搬运或鸡汤）
- [ ] 是否有个人辨识度（框架/比喻/金句）
- [ ] 结尾是否有力且正向
- [ ] 平台字数与标题风格是否符合（见 `references/style-guide.md`）

## 审核报告模板

每次审核/修改交付时按此结构输出（可合并进正文回复，不必单独成文）：

```
## 审核结果
- 原创性等级：极高 / 高 / 中 / 低
  - 依据：[命中哪些过关信号 / 哪些不过关信号]
- 限流风险：高 / 中 / 低
  - 极高危 X 处、高危 X 处、中危 X 处

## 修改逻辑表
| 原文 | 改后 | 风险类型 | 处理方式 |

## 完整改后版本
[正文全文]

## 自检结果
[四条执行标准逐项打勾]
```
