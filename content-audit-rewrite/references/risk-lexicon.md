# 限流风险识别词库

公域平台审核红线的速查手册。**任何改写在交付前都必须逐条核对本表。**

## 三级风险总览

| 级别 | 处理原则 |
|---|---|
| 🔴 极高危（必须删除或彻底重写） | 不保留任何指向，整段处理 |
| ⚠️ 高危（必须替换） | 换成安全等价表述 |
| ⚡ 中危（需微调） | 压缩、弱化或泛化 |

---

## 🔴 极高危（必须删除或彻底重写）

| 风险类型 | 示例 | 处理方式 |
|---|---|---|
| 政治历史人物具体细节 | 对历史人物被排挤、被撤职的详细描写 | 删除具体细节，用"历史经验"泛化 |
| 对法律/司法/制度的直接批评 | "某法就是个笑话""某保护法成保护伞" | 整段删除，不保留任何指向 |
| 对政府应对能力的负面预判 | "政府反应一定会慢" | 删除 |
| 社会批判/阶层对立 | "资产阶级的风险管理包装成人生哲学" | 替换为"有产者""已积累者" |
| 具体品牌/人物的负面评价 | "某厂商推个产品出来抢流量" | 泛化为"有些厂商急于商业化" |
| 商业引流 | "进粉丝群拿""语音课里讲得更系统" | 全部删除 |

## ⚠️ 高危（必须替换）

| 风险类型 | 高危词 | 替换方案 |
|---|---|---|
| 医学/心理学诊断 | PTSD、抑郁症、精神病、人格障碍、杏仁核劫持 | 创伤感、心理困境、内在冲突状态、本能保护机制 |
| 宗教/灵性/玄学 | 灵魂等级、宇宙、能量场、神性、业力、华盖、印星、食伤、官杀、识神、元神 | 内在成熟度、客观规律、心理状态、内在力量、惯性模式、孤独特质、思虑型、表达型、后天意识、先天觉知 |
| 性别对立/群体标签 | 捞女、雄竞女、低认知的人、巨婴、穷屌丝 | 某些人、视角差异较大的沟通对象、需要情绪关照的沟通对象 |
| 绝对化表述 | 没有人会真的对你好、唯一只有你自己 | 不要指望所有人都会真心对你好、你可以学会对自己好 |
| 粗俗词汇 | 傻逼、你他妈、狗屁、舔着脸、肉鸡、滚出去 | 删除，或替换为中性的"硬推""注意力供应者""离开" |
| 政治隐喻 | 被某国驻军的国家、土皇帝操作系统 | 让渡了部分决策权给你、另一副面孔 |
| 宗教典籍密集引用 | 《道德经》说、庄子说、佛家叫它 | "古人说""有一个说法" |

## ⚡ 中危（需微调）

| 风险类型 | 示例 | 处理方式 |
|---|---|---|
| 负面情绪密集 | 连续多段描写痛苦、绝望、崩溃 | 压缩篇幅，增加正向收束 |
| 攻击性标题 | "落得如此下场""身边人越想攻击你" | 改为中性提问或"打断你" |
| 具体平台名称 | 抖音、朋友圈、直播间 | 泛化为"屏幕里""社交平台" |
| 具体金额/城市 | 二线100平米房、30万车 | 泛化为"基础生活保障" |
| 对特定群体的概括 | 中国式家长、东亚教育 | 弱化为"某些高压的家庭和职场环境" |

---

## 高危词库速查（必须删除或替换的词）

**政治类**：阶级、资本家、底层人群、剥削、奴隶制、政府反应慢、法律是笑话
**医学类**：PTSD、抑郁、精神病、人格障碍、神经病症、杏仁核劫持
**宗教类**：灵魂等级、业力、神煞、道心、识神、元神、华盖、印星、食伤、官杀
**攻击类**：傻逼、你他妈、狗屁、舔着脸、肉鸡、滚出去、巨婴、捞女
**绝对类**：没有人、唯一、所有、永远、必须
**引流类**：进群、课程、私信、粉丝群、语音课

## 收束句式库（正向收束用）

批判性内容后必须补建设性结尾，以下句式可直接选用或仿写：

- "看清规则，不是为了绝望，而是为了不再稀里糊涂地参与一场不属于自己的游戏。"
- "你不是不够努力——你是还没敢看清：谁在靠你的'不够好'活着。"
- "那些绑在你身上的东西，你可以不受的。"
- "你不需要跑得很快，你只需要跑得比别人久。"
- "真正活着的人，不需要自信，他们只需要存在。"
