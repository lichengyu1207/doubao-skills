# 诊断与定档（dingdang）

## 1. 诊断问题清单（每次先收集）

| 维度 | 问题 | 目的 |
|---|---|---|
| 场景 | 主场景是自媒体 / 创业 / 副业 / 企业？是否多场景并行？ | 确定打法分支 |
| 现状收入 | 当前年收入 / 月收入约多少？收入来源是什么？ | 判断所处档位 |
| 时间 | 每周能投入几小时？（全职 = 40+，兼职 = 10–20） | 判断节奏可行性 |
| 资金 | 可投入本金多少？最多能承受亏损多少？ | 判断风险边界 |
| 技能 | 会写 / 会拍 / 会剪 / 会卖 / 有行业经验？ | 匹配打法路径 |
| 资产 | 已有账号、客户、货源、团队、资质？ | 盘点起点资源 |
| 目标 | 目标档位（10万/100万/1000万）与时限（1年/3年） | 定档与拆解 |
| 约束 | 主业占用、家庭负担、负债情况 | 设定安全垫 |

用户未提供时：允许用户跳过不愿回答的项，但「目标档位 + 时限 + 每周时间」三项必须有，否则不给路线图、先补齐。

## 2. 现状卡模板（输出格式）

```
【现状卡】
起点：目前收入 ___ /月，来源 ___
可用时间：每周 ___ 小时（全职/兼职）
可用资源：本金 ___ / 技能 ___ / 已有账号·客户·团队 ___
限制条件：___（主业占用、负债、家庭等）
目标档位：___ 万 / 时限 ___
```

## 3. 档位判定规则

按「当前收入 → 目标档位」分级，参考基准（年收入口径）：

| 当前年收入 | 所处档位 | 特征 |
|---|---|---|
| < 10万 | 起步前 / 10万档早期 | 尚未跑通稳定收入 |
| 10万–100万 | 10万档 → 100万档过渡 | 有稳定单一收入来源 |
| 100万–1000万 | 100万档 → 1000万档过渡 | 有团队/标准化产品/多渠道 |
| ≥ 1000万 | 1000万档 | 组织化运营，系统赚钱 |

## 4. 跳档规则（重要）

- **一次只跳一档**：10万 → 100万 → 1000万 逐级跳。越级跳档（如从 0 直接规划 1000万）是失败主因，必须指出并建议分阶段。
- 用户坚持越级时：先给目标档位愿景，再强制回到「当前档位 → 下一档」的第一阶段路线。
- 时限不匹配时：提示现实区间（10万档通常 6–18 个月，100万档通常 2–3 年，1000万档通常 5 年以上），不承诺时限。

## 5. 定档输出

一句话结论 + 差距分析：
> "你现在处于 10万档早期（月收入约 4000），目标 100万档。中间差 1 档，先完成 10万档闭环（月入稳定 8000+、单渠道跑通），预计 12 个月，再上 100万档。"
