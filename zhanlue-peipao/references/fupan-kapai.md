# 复盘与里程碑（fupan-kapai）

## 1. 月复盘卡片（每月 1 次，30 分钟）

输出固定结构：

```
【月复盘卡】日期：____
关键数据：月收入 ___ / 上月 ___（环比 __%）；触达 ___；成交 ___；客单价 ___
完成动作：本月做对了什么（3 条以内）
问题：本月最大的 1 个问题（现金流 / 流量 / 交付 / 团队）
下月重点：3 件事（1 增长 + 1 现金流 + 1 能力）
档位判断：仍在本档 / 接近升档 / 需要降档调整
```

## 2. 里程碑检查表（按档位核对）

### 10万档通过标准（全部满足才升档）
- [ ] 连续 3 个月月收入 ≥ 目标 60%
- [ ] 1 个主渠道稳定出单（周出单 ≥ 3 次）
- [ ] 交付流程可写成文字/视频 SOP
- [ ] 单客户获取成本可计算、可接受

### 100万档通过标准
- [ ] 主产品 SOP 化，他人可接手交付
- [ ] 团队 ≥ 2 人且分工明确（非创始人一人全扛）
- [ ] ≥ 2 个渠道稳定产出
- [ ] 私域沉淀 1000+ 精准客户，复购率可统计
- [ ] 账上现金 ≥ 3 个月运营成本

### 1000万档通过标准
- [ ] 创始人脱离一线仍可运转（组织自运行）
- [ ] 至少 1 个可复制扩张模式已验证（加盟/代理/多线）
- [ ] 品牌有辨识度（自然搜索/转介绍占比可查）
- [ ] 财务、税务、法务、用工四件套合规无遗留
- [ ] 数据看板覆盖收入、利润、渠道、人效

## 3. 升档判定清单

出现以下任一组合，即可建议筹备升档：
- 现金流：连续 3 个月月收入达到当前档上限的 2 倍
- 产能：主渠道/主产品产能饱和，增长需靠新增人/产品/渠道
- 时间：交付占个人时间 > 60%，且标准化条件已具备
- 复购：复购/转介绍占比 ≥ 30%

出现以下信号，建议降档或收缩：
- 现金 < 3 个月运营成本
- 主渠道连续 2 个月下滑且无替代渠道
- 新业务线连续 6 个月亏损且无战略价值

## 4. 复盘纪律

- 数据只看事实，不看情绪；没有数据就标"待统计"，不编数
- 复盘后必须有"下一步动作"，否则复盘无效
- 每次复盘先看现金，再看增长，最后看团队
