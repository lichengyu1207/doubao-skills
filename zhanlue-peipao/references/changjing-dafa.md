# 四场景打法（changjing-dafa）

四类主场景：自媒体、创业、副业、企业。先判定用户主场景，再按下表调整路线图；多场景用户给出"主场景 + 副场景"组合与优先级。

---

## 一、自媒体

**本质**：内容即产品，信任即渠道。链路：定位 → 内容 → 流量 → 信任 → 私域 → 变现。

### 打法要点
- **定位**：垂直细分 × 真实卖点 × 差异化；一句话能说清"我帮谁解决什么问题"
- **内容**：图文 / 短视频 / 音频选 1 种主形式；50 条选题库起步；固定节奏（宁少而稳，不追多而断）；原创不搬运
- **平台**：主战场 1 个做深，其余同步分发；看目标人群在哪，不追热点平台
- **变现路径由近及远**：接单/服务 → 数字产品/资料 → 课程/训练营 → 咨询/代运营 → 广告/带货
- **量级参考（不承诺收益）**：粉丝数不直接等于收入，看精准度与信任度；小而精准（千粉深粉）优于大而泛（十万泛粉）

### 档位适配
- **10万档**：单平台起号，跑通第一笔变现（广告/带货/卖课任一）
- **100万档**：多平台矩阵 + 私域运营 + 产品线（课程/社群/服务）
- **1000万档**：MCN/矩阵化/平台化运营，靠系统与签约作者赚钱

### 红线
- 不搬运、不洗稿、不伪造数据截图；带货不虚假宣传；医疗/金融等资质领域先提示合规

---

## 二、创业（个人/小团队公司）

**本质**：解决一个真实问题，赚取解决问题的回报。链路：验证 → 最小产品 → 现金流 → 团队 → 系统。

### 打法要点
- **验证优先**：先成为目标客户/做一线调研，确认真实需求（区分真需求与伪需求）
- **最小产品**：先有后优，60 分上线，小步试错
- **现金流为王**：收入 > 支出是保命线；创业前留 6 个月生活费 + 应急金；账上现金 ≥ 3 个月运营
- **聚焦**：先打游击战（哪个能活做哪个）再打持久战；不盲目多元化
- **团队**：小团队先招"合适的人"而非"最强的人"；合伙人权责利书面化
- **合规**：税务、资质、合同、用工四件套尽早规范

### 档位适配
- **10万档**：验证需求 + 跑通最小盈利模型（个人或 2 人）
- **100万档**：产品标准化 + 2–5 人团队 + 2–3 渠道
- **1000万档**：组织制度 + 品牌 + 渠道网络/多产品线 + 财务合规体系

---

## 三、副业

**本质**：用主业的空余时间与既有技能，低成本试错第二收入曲线。

### 打法要点
- **时间盘活**：明确每周可投入小时数（10–20 小时是现实区间），按小时排优先级
- **低成本试错**：单项目测试投入设上限（如 ≤ 500–2000 元），跑不通即换
- **主副协同**：优先选择与主业技能/资源相关的方向（行业经验即壁垒）
- **先跑通再加大**：连续 3 个月月入稳定后，再考虑扩大投入或全职转创业
- **安全垫**：副业阶段不动用生活必需资金；不借贷加杠杆

### 档位适配
- **10万档**：副业月入 8000+ 可视为"可全职"的信号；先并行、后切换
- **100万档**：需全职化 + 团队化，纯副业时间基本到顶
- **1000万档**：副业逻辑不再适用，需正式公司化运营

---

## 四、企业（中小企业/团队）

**本质**：组织化增长。链路：战略 → 组织 → 渠道 → 品牌 → 财务合规 → 规模化。

### 打法要点
- **战略**：明确主营业务与差异化；砍掉不赚钱业务线
- **组织**：岗位职责、授权体系、考核激励；创始人脱离一线仍能运转
- **渠道**：直销/分销/线上/线下多渠道；渠道数据化
- **品牌**：定位、内容资产、客户口碑；从"卖货"到"卖信任"
- **财务合规**：核算、现金流、税务、法务、内控；融资与对赌条款审慎
- **扩张**：模式验证后再复制；不盲目追风口

### 档位适配
- **10万档**：小微企业起步，跑通单产品单渠道盈利
- **100万档**：团队化（5–20 人），多产品线或多渠道
- **1000万档**：组织制度成熟、品牌成型、可考虑渠道网络/加盟/资本化

---

## 多场景组合规则

- **自媒体 + 副业**（最常见）：自媒体是获客渠道，副业是变现载体；主攻内容，产品跟进
- **创业 + 自媒体**：用内容获客降低获客成本；内容团队与销售团队分工
- **企业 + 自媒体**：企业提供产品/供应链，自媒体提供品牌与流量入口
- 多场景时：只设 1 个主引擎，其他为辅助；按"现金流最快为正"的优先级排
